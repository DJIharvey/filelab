# FileLab for Netlify

FileLab is an independent static site hoster.

## Deploy

1. This repo is connected to Netlify.
2. Netlify runs `npm install` and deploys the function.
3. Set environment variable `APP_SECRET` to any long random string.

## Use

1. Open your Netlify URL.
2. Create an account.
3. Create a site — it becomes a public website at `/s/your-site-name/`.

Netlify only hosts the FileLab app. FileLab makes the websites.
